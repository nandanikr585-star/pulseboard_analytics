# PulseBoard Analytics

## Project Overview

PulseBoard Analytics is a data analytics project that explores life expectancy data to identify trends, patterns, and meaningful insights.

## Objectives

* Clean and preprocess life expectancy data.
* Perform Exploratory Data Analysis (EDA).
* Store and analyze data using SQL.
* Generate insights from the dataset.

## Tools and Technologies

* Python
* Pandas
* Jupyter Notebook
* SQL
* SQLite

## Project Structure

* `data/` — Raw and processed datasets
* `notebooks/` — Data exploration and analysis
* `scripts/` — Python scripts for data loading and processing
* `sql/` — SQL queries and database files
* `cleaning_log.md` — Data cleaning notes

## How to Run

1. Clone or download this repository.
2. Install Python and the required libraries.
3. Run the Python scripts from the `scripts/` folder.
4. Open the notebook in `notebooks/` to explore the analysis.
5. Execute SQL queries from the `sql/` folder.

## Expected Outcome

To understand life expectancy patterns through data cleaning, exploratory analysis, and SQL queries.
